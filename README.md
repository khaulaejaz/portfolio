# Portfolio Website

This repository contains a basic personal portfolio website created as part of my practice in HTML and CSS. The project focuses on building a simple layout and organizing content into clear sections.

##Overview

The website includes:

-About section

-Skills

-Projects

-Contact information

It is built using plain HTML and CSS without any external libraries or frameworks.

##Purpose

This project was created to practice fundamental front-end concepts, including page structure, semantic HTML, styling, and working with static assets.
